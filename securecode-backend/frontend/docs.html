🚀 Installation Guide

Downloadable CLI — syntax and indentation

This script checks individual Python files for syntax and indentation issues. It does not run security or quality checks and does not scan folders.

⬇️ Download cli.py

Usage

python3 cli.py myfile.py

Full security scanner — from a repository checkout

Run the root CLI to scan one or more Python files or recursively scan a project folder for syntax, security, and code-quality findings. The CLI does not execute scanned code.

python3 cli.py myfile.py
python3 cli.py ./my-project
python3 cli.py ./my-project -o findings.json
python3 cli.py ./my-project -o findings.pdf

⚙️ Setup Guide

Prerequisites

Make sure you have Python 3.6+ installed on your system.

Backend Setup

Install dependencies and start the API server:

cd securecode-backend
pip3 install -r requirements.txt
python3 manage.py runserver 127.0.0.1:8000

Frontend Setup

In a separate terminal, start the frontend server:

python3 serve_frontend.py

Access the Application

Open your browser and navigate to:

http://127.0.0.1:3000/

  • 🔍 Security vulnerability detection
  • 📊 Code quality analysis

  • 📝 Detailed reports generation
  • 💻 CLI and web interface
  • 🔒 Submitted code is analyzed, not executed
  • 📁 Web scans one file; CLI scans project folders
