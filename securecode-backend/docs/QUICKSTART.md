# Full App Quick Start

From the repository root, run `./run-local.sh`. It installs dependencies, applies migrations, and starts the full backend with the React UI bound to `127.0.0.1`. Open http://127.0.0.1:3000/; the API is at http://127.0.0.1:8000/api/. This setup is for local access on the same computer.

For setup details and the API-only option, see the repository [Quick Start](../../docs/QUICKSTART.md).
